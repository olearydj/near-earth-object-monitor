# Contributing

Small corrections, documentation improvements, and focused features are welcome through pull requests.

1. Read `README.md` and `AGENTS.md`, then check existing pull requests.
2. Fork the repository, clone your fork, and create a purpose-named branch.
3. Make one focused change. Update documentation and tests when needed.
4. Run the checks listed in `AGENTS.md` and inspect the complete diff. The test
   suite uses committed fixtures and mocked responses, so it does not require a
   NASA API key or live NASA access.
5. Commit the change and push the branch to your fork.
6. Open a pull request into `olearydj/near-earth-object-monitor:main`.

In the pull-request description, explain what changed, why it helps, and how you verified it. Do not include secrets, generated data, local environments, logs, or unrelated cleanup.

If revisions are requested, commit them to the same branch and push again. GitHub will update the open pull request automatically.
